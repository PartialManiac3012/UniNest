# UniNest (React)
Vite + React 18 + React Router + Tailwind. Design tokens come from the Collegiate Editorial Broadsheet system (see tailwind.config.js and src/index.css).
    npm install && npm run dev
Routes: / (home), /signup, /login, and (after login) /dashboard, /directory, /events. Accounts are stored in localStorage (demo auth, see src/auth.jsx); email codes are shown on screen until you connect an email service.
